|---|---|---|---|
| D-01 | SQLite default, PostgreSQL 16/PostGIS in compose; geometry stored as GeoJSON JSON, spatial logic in Shapely | GeoAlchemy2 + PostGIS everywhere | Zero-setup local runs and tests; spatial queries at MVP scale (<10k plots) are done in-process. Move hot paths to PostGIS `ST_Intersects` when volume needs it. |
| D-02 | `create_all` at startup + Alembic baseline migration | Alembic only | Dev needs no extra step; production uses `alembic upgrade head`. |
| D-03 | Plain scheduler loop (`workers/scheduler.py`) | Prefect, Celery+Redis | One process, no broker, idempotent daily job; Redis dropped from compose. Revisit for horizontal scale. |
| D-04 | Offline imagery mode = deterministic synthetic NDVI/SAR scenes (default); STAC search implemented, raster reads need `real` extras | Ship real COG fixtures | No network/keys needed; reproducible results. **Real-data pixel reads (rasterio/odc-stac) are NOT implemented/tested** - raises `NotConfigured`. |
| D-05 | Field-capture signing: C2PA-style manifest signed Ed25519 (dev key auto-generated) + SHA-256 hash chain; real `c2pa-python` embedding hook (`embed_c2pa`) present but untested | c2pa-python only | Works offline, tamper-evidence tested. Dev key is not a trusted C2PA identity. |
